## ✦ Highlights

- ⚡ **Fast & static** — App Router + React Server Components, optimized fonts & images
- 🎛️ **SOC-style dashboard** — an honest, at-a-glance snapshot with count-up stats
- ⌘ **Command palette** — jump anywhere with `⌘K` / `Ctrl-K`
- ▸ **Interactive terminal** — real navigation via typed commands (`help`, `whoami`, `projects`…)
- 🧭 **Recruiter mode** — one toggle for reduced motion, quick links, and a prominent résumé download
- 🗂️ **Case-file projects** — incl. **SeCPoD**, an end-to-end insider-threat detection platform
- ✍️ **MDX write-ups** — drop a file in `content/` and it ships (blog · case studies · lab · research)
- 🌗 **Dark / light**, keyboard-accessible, and reduced-motion aware
- 🔎 **SEO-complete** — sitemap, robots, web manifest, dynamic OG image, and `Person` JSON-LD

## 🛠️ Built with

`Next.js 16` · `React 19` · `TypeScript` · `Tailwind CSS v4` · `Motion` · `MDX` · `cmdk` · `Lucide`

## 🚀 Run locally

```bash
npm install
npm run dev          # → http://localhost:3000

npm run build        # production build
npm run lint         # ESLint
npm run typecheck    # tsc --noEmit
```

## 🗂️ Structure

```
app/          App Router routes (+ the (site) layout group)
components/    reusable UI, effects, and providers
features/      page-level sections (dashboard, terminal, skills…)
data/          typed content — the single source of truth
content/       MDX posts (blog · case-studies · lab · research)
lib/           utilities
```

## ✍️ Adding a post

Drop an `.mdx` file into `content/<section>/` with frontmatter — it appears automatically.
See [`content/README.md`](content/README.md).
